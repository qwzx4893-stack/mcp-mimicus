# Source integration and acceptance

This release has seven named source adapters. Six provide live retrieved candidates; Awwwards supplies a restricted, explicit operator-reference workflow because no special content authorization has been provided. Adapter presence, a successful protocol call, and full-catalog coverage are different claims.

The repeatable evidence command is `node scripts/source-release-acceptance.mjs` after building. It launches the **production** stdio server with official `@modelcontextprotocol/client` 2.3.1, tests each source independently, tests all three Codrops streams separately, and closes each RAM operation. It exports counts, timestamps, coverage, diagnostic text and identity hashes to `artifacts/final-release/source-acceptance.json`; it does not export source records, image files, model vectors or a site index. Actual current counts can change upstream.

## Awwwards capability decision

Current upstream software reviewed: [INSANE0777/Awwwards-mcp at ef6b5631206524942ff1cc3ecb17f5218e70c60d](https://github.com/INSANE0777/Awwwards-mcp/tree/ef6b5631206524942ff1cc3ecb17f5218e70c60d), committed 2026-10-18. Its MIT notice credits Afjal. The retained split/card parser was compared with the current `src/parsers.ts`; current `src/server.ts`, `src/structure.ts`, `src/design-brief.ts`, and the `awwwards-inspiration` workflow were also reviewed. Useful separation of visual evidence, missing information and original implementation informs the browser/synthesis workflow. The upstream persistent index, image cache, watchers, preferences database and capture-and-rehost examples are not imported.

[Current Awwwards terms](https://www.awwwards.com/terms/) reserve source content rights and require express authorization for commercial use. [Current robots](https://www.awwwards.com/robots.txt) disallows automated search paths including `/search-websites`, `/websites/?` and `/elements/*`. Robots is an access signal, not a content license; MIT covers software, not the gallery's content. Temporary RAM processing does not grant a missing license. Ordinary public navigation links are exposed for the operator, without claiming an automated gallery connection.

| Sub-capability | Release status | Evidence/usable path |
| --- | --- | --- |
| Automated catalog search, details, classifications, makers and design elements | Restricted | No special authorization. Default adapter makes zero Awwwards HTTP requests and explains the restriction. Historical 31-card connectivity is not reused as authority. |
| Awwwards-owned screenshots/video/inline previews | Restricted | No automatic media download, mirror or redistribution. |
| Public gallery navigation for the operator | Available as a link | Source-provided public gallery entry and current terms link are returned; the operator can choose a reference in ordinary browsing. |
| Known original-site / reference-link handoff | Available, operator supplied | `originalReferences: [{title, url, listingUrl}]`, maximum eight, with exact HTTPS `www.awwwards.com/sites/...` links and credential-free original URLs. Relationship, title and classification remain unverified source claims. |
| Original-site screenshots, structure, menu interaction, filmstrips, targeted measurements | Available through separate authorized browser session | Use returned original `referenceId`, then `mimicus_open_reference`. Original-origin public-IP/robots/resource constraints still apply. Availability of the original site is verified when opened, not inferred from the gallery link. |
| Multi-reference direction and independent implementation | Available from inspected evidence | Use browser images and actual measurements. Missing evidence remains missing; branded media or proprietary source is not copied. |

Operator flow: manually select a reference → provide its original URL and exact Awwwards source link → call `mimicus_search` with `providers: ["awwwards"]` and `originalReferences` → select its returned ID → call `mimicus_open_reference` with the operation/ID and `authorized: true` → inspect real screenshots/interactions → close browser and discovery operation. This path does not verify award status or silently enable catalog extraction. Any potential official access request is a documentation task; no maintainer or third party has been contacted.

## Webflow public interface provenance

The shipped Made in Webflow client was examined on 2026-10-19. Its current `2550-6a25617c1df7837b.js` and `1086-e196de6c1ebfd516.js` chunks construct the public native feed and full-text search calls; the current `_app-42b4942a009cd747.js` publishes the search endpoint and public Engine Key. The adapter implements that browser-visible, read-only contract independently. It does not use an account/private API key, an authenticated browser, internal admin routes, analytics writes, likes or clone APIs.

[Webflow robots](https://webflow.com/robots.txt) explicitly permits `/api/v1/marketplace/made-in-webflow/` and declares search/AI-input signals; the general `/api/` deny still applies elsewhere. The public search service's robots endpoint returned 404. [Swiftype's official overview](https://swiftype.com/documentation/site-search/overview) and [search reference](https://swiftype.com/documentation/site-search/searching) document public Engine Keys as read-only client search identifiers. The identifier in the adapter is intentionally published by Webflow's browser client, not the user's GitHub token or a private service credential. Actual source robots rules are checked again before requests. No search response or engine payload survives the operation on disk.

## Pagination, freshness and result interpretation

- Independent queries allocate a fresh transport scope and issue fresh source requests. A RAM operation can coalesce identical URLs only while a call is running. Explicit continuation is `{operationId}`; it retains the original query, filters and native sort.
- `hasMore`, each source's `next` cursor and coverage identify available continuation. Full feed pages suggest another page rather than proving the provider's total. Webflow source offsets/pages are bounded at 10000; normal request, byte, candidate and operation-TTL budgets also apply.
- A continuation returns results from the newly retrieved source pages. Earlier retained references remain addressable by ID until TTL/closure/eviction. The result reports `resultScope`, candidate counts and eviction; it does not repeatedly hide new pages behind old top-ranked results.
- Canonical original URLs merge relationships across sources, preserving each native classification and maker. Missing metadata is omitted, not inferred. Semantic similarity is a computed ranking signal, not a provider's aesthetic score or style label.
- Upstream pagination is not snapshot isolation: a source can add/remove/reorder records between calls. A repeated HTTP response hash may remain the same because the source did not change; the independent request count establishes a new request, not an invented freshness change.
- `available` for Nuxt means the current maintained YAML was read, not that every original website was opened. `partial` identifies bounded pages, incomplete labels or native restrictions. Source failure returns diagnostics without stale disk fallback and without disabling the other adapters.

## Defects found by actual MCP acceptance

1. Continuation initially repeated retained top-ranked results and concealed new pages. The federation now ranks the current batch on continuation while keeping bounded old references addressable.
2. The MCP boundary applied default query/retrieval/limit fields before a continuation reached the federation, causing a false filter-change rejection. The wire schema now preserves omitted fields; first-query defaults apply internally. Actual SDK continuation is covered by regression tests.
3. Older Webflow entries can contain empty native tags. Source normalization now removes empty/invalid labels, retains the valid original record and preserves actual nonempty labels. The observed failing round is retained as `source-acceptance-round2-defect.json`; final acceptance must show this path working.

The test program distinguishes expected Awwwards restriction from source retrieval success and fails its acceptance gate if a required permitted path returns unavailable/empty results. It records no catalog payloads. Unit fixtures test malformed URLs, unverified manual handoff, missing metadata, exact native route/query construction, pagination and source classification semantics; they are not counted as live source connectivity.
