## Descriptive assisted/control comparison

The same Relay brief, functions, palette, system fonts and original asset constraints were supplied to an unassisted agent. It used no external discovery, preview or brief tools and did not read the assisted file. [Control evidence](https://github.com/qwzx4893-stack/mcp-mimicus/blob/v0.4.0-beta.1/artifacts/product-hardening/saas-control.md) records8m14s and29 MCP QA calls, including a reproduced focus repair. Both agents could QA their own output with the owned browser; reference assistance was withheld only from the control.

The final assisted agent began20 October at14:57:15UTC and finished15:09:12UTC:717.2 seconds, versus the control's494 seconds. Both used the same functional brief,15-minute maximum, palette/system fonts and independently authored assets. The assisted agent did not read the control or earlier assisted code. Actual elapsed time includes their respective work and fixes; bridge-call totals differ in composition and are not standardized token/compute costs.

A fresh reviewer inherited no conversation history, source HTML, production reports or condition mapping. It inspected opaque A/B URLs at1440×900 and390×844 with30 actual RAM screenshots and28 equal interactions. [Frozen final review](https://github.com/qwzx4893-stack/mcp-mimicus/blob/v0.4.0-beta.1/artifacts/product-hardening/saas-final-review.md) scored A22/24 and B24/24 before mapping was revealed. A was the final assisted output; B was the control. Both passed matched functional checks. The control had more direct action/product hierarchy and a more compact mobile fold; the assisted page repeated introductory content and crowded long FAQ labels. The control scored higher and finished faster in this pair. These ordinal AI judgments are descriptive, not a validated aesthetic scale or a blind human panel.

The [earlier review](https://github.com/qwzx4893-stack/mcp-mimicus/blob/v0.4.0-beta.1/artifacts/product-hardening/saas-review.md) tied20/24 for control versus the interrupted first assisted output, now retained separately as [interrupted implementation](https://github.com/qwzx4893-stack/mcp-mimicus/blob/v0.4.0-beta.1/examples/workflow/hardening-saas-interrupted.html). Its interrupted timing cannot support a matched cost comparison. It is not substituted for the completed final trial.

One completed pair cannot establish typical design quality, conversion, cost or causality. No aesthetic or efficiency superiority is established. The evidence supports useful reference inspection, grounded implementation decisions and concrete failure detection; the comparative evaluation gate remains PARTIAL.

Source screenshots remain temporary MCP responses. Reports export URLs, hashes, bounded measurements and independently authored demo code. Supplemental owned-page browser assertions are labeled separately; Mimicus deliberately cannot submit forms or evaluate arbitrary page JavaScript. Cleanup counts are verified per client.
