# Coding-agent quality evaluation

Five new distinct real SDK workflows are required: coffee retail, creative agency, immersive WebGL2, conversion-oriented SaaS, and architecture/cultural editorial. Each must discover actual references, view multiple images, make an evidence-backed choice, inspect an interaction, author an original implementation, review desktop/mobile output, verify chosen constraints and clean up.

The five new original outputs have actual discovery, image review, selected analysis/spec, desktop/mobile QA and cleanup evidence. Some execution was interrupted by the account usage limit: agency/immersive code was prepared after earlier real previews, then independently revisited on recovery. Their reports distinguish inherited code from new observations. The assisted SaaS segment was interrupted before QA, invalidating a strict uninterrupted15-minute cost comparison. Earlier0.3 coffee/immersive trials remain historical and are not renamed as these tasks.

## Descriptive assisted/control comparison

The same Relay brief, functions, palette, system fonts and original asset constraints were supplied to an unassisted agent. It used no external discovery, preview or brief tools and did not read the assisted file. [Control evidence](https://github.com/qwzx4893-stack/mcp-mimicus/blob/main/artifacts/product-hardening/saas-control.md) records8m14s and29 MCP QA calls, including a reproduced focus repair. Both agents could QA their own output with the owned browser; reference assistance was withheld only from the control.

An independent agent inspected opaque A/B URLs at1440×900 and390×844 with equal interactions before receiving condition mapping. [Frozen review](https://github.com/qwzx4893-stack/mcp-mimicus/blob/main/artifacts/product-hardening/saas-review.md): A20/24, B20/24. A was the unassisted control, B the assisted output. A had stronger mobile action/filter compactness; B had clearer upfront local-demo wording and earlier product visibility. There was no clear winner. The reviewer was an AI with shared project context, not a fully blind human panel. These ordinal scores are descriptive judgments, not a validated aesthetic scale.

The assisted run's interruption and recovery prevent matched timing inference. One pair cannot establish better aesthetics, conversion, typical cost or causality. The evidence supports useful reference inspection and grounded implementation decisions, while demonstrating concrete failure detection; the comparative evaluation gate remains PARTIAL.

Source screenshots remain temporary MCP responses. Reports export URLs, hashes, bounded measurements and independently authored demo code. Supplemental owned-page browser assertions are labeled separately; Mimicus deliberately cannot submit forms or evaluate arbitrary page JavaScript. Cleanup counts are verified per client.
