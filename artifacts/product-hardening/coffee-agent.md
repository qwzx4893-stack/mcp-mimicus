# Aster Roasting agent exercise

Original output: [coffee storefront](https://github.com/qwzx4893-stack/mcp-mimicus/blob/v0.4.0-beta.1/examples/workflow/hardening-coffee.html).

The brief is a small-batch coffee retailer: an editorial proposition, three clearly differentiated coffees, roast filtering, roasting story and local subscription-plan preview. Product selection and conversion are explicit priorities. The original palette combines paper/coffee-ink with slate blue and acid-green labels; bag/cup artwork is independently authored inline SVG/CSS, not copied website media. Prices and product facts are illustrative; no purchase or account service is connected.

Fresh Astro/Nuxt discovery on19 October found I Brew My Own Coffee and Tchibo; actual images were viewed before code. Jura failed its open deadline. The useful references supplied a compact navigation/label relationship and repeatable retail item structure, while the agent chose an independent hero, typography, tokens, copy and product art. Selected navigation hover and1280/390 measurements/spec were retrieved. Comparison exposed an offscreen skiplink and1px hidden h1 being chosen as guidance anchors; the production selection was corrected and regression-tested.

After the usage-limit interruption, a fresh final-runtime SDK workflow began20 October09:48:08UTC. It opened both actual references, compared the product-selection brief, measured navigation at1280/390, fetched a spec, opened the original storefront, viewed desktop/mobile frames and exercised roast filter, chosen-coffee dialog, menu/Escape and focus behavior. Supplemental [owned functional assertions](https://github.com/qwzx4893-stack/mcp-mimicus/blob/v0.4.0-beta.1/artifacts/product-hardening/owned-functional-qa.json) tested local form confirmation, correct selected blend, rhythm and keyboard return.

Verification intentionally did not claim identity: the reference uses a fixed bottom navigation, the original a top static header. A multi-width nav verification initially refused because the original mobile navigation was hidden; desktop-only comparison then returned false tolerances for position/gap/width/height. State must be selected before comparing it, and a different original design is not an aesthetic failure.

The agent revisited and captured both references after more than20 real minutes, with explicit idle renewal preserving the same absolute deadlines and cumulative budgets. [Round-one timeline](https://github.com/qwzx4893-stack/mcp-mimicus/blob/v0.4.0-beta.1/artifacts/product-hardening/long-workflow-round1.json) records actual timestamps. One close was delayed; all counters eventually reached zero after the other owned sessions closed. This negative led to a teardown correction and a simulated unresponsive-context RPC regression using a real owned browser. The final browser reliability report distinguishes first-run evidence from the subsequent corrected run.

At least30 actual Mimicus calls were manually reconstructed across discovery, preview/open, comparison, selected analysis/spec, interaction, verification, renewal and cleanup; this is a lower bound rather than instrumented complete telemetry. Third-party frames remained in RAM. The late cleanup delay and hidden-mobile verification refusal are retained as failures, not counted as successful operations. The earlier account outage is excluded from the extended workflow duration.
